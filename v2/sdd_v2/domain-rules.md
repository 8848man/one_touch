# 앨범 규칙

MVP `sdd/core/domain/domain-rules.md`를 대체한다. 번호는 V-로 새로 매긴다.

| # | 규칙 | MVP 대비 |
|---|---|---|
| V1 | 앨범 = 앱 레코드 + 기기 폴더. 앱에서 만든 앨범은 `Pictures/<folderName>`, 가져온 앨범은 원래 경로(`relativePath`) | DR-1 유지 |
| V2 | 리스트에는 앱에서 만든 앨범 + 기기에서 가져온 앨범이 모두 나온다. 칩에는 켜 둔 앨범만 나온다 | DR-2, DR-14 변경 |
| V3 | 저장 대상은 **표시 중인** 앱 앨범뿐이다 | DR-3, DR-11 유지 |
| V4 | 이름 중복 검사는 앱 앨범의 표시 이름끼리, 공백 제거 후 비교 (대소문자 무시). 메시지: `동일한 이름의 앨범이 이미 존재합니다.` | DR-4 유지 |
| V5 | 새 앨범은 표시 on, 리스트 맨 아래, 바로 현재 선택 앨범이 된다 | DR-15 유지 |
| V6 | 폴더는 첫 저장 때 만들어진다 (Android). 그 전까지 사진 수 0 | DR-9 유지 |
| V7 | 이름 변경은 표시 이름과 **기기 폴더 이름을 함께** 바꾼다. Android에는 폴더 이름 변경 API가 없으므로 폴더 안 사진·동영상을 같은 상위 경로의 새 폴더(`DCIM/Camera/` → `DCIM/<새 이름>/`)로 옮긴다. 시스템 확인을 거부하면 아무것도 바꾸지 않는다. Android 10 이하는 표시 이름만 바꾼다. 표시 토글은 유지 | DR-8 변경 (v1.1) |
| V8 | 삭제는 앱 레코드만 지운다. 폴더와 사진은 남는다 | DR-5 변경 |
| V9 | 선택 앨범이 숨김/삭제되면 남은 표시 앨범 중 최근 사용 앨범을 고른다. 없으면 정렬 순서상 첫 앨범 | DR-12 유지 |
| V10 | 표시 앨범이 0개면 촬영 불가, 칩 자리에 "앨범을 만들어 주세요" | DR-13 유지 |
| V11 | 마지막으로 **촬영한** 앨범을 기억했다가 다음 실행 때 선택 | DR-7 유지 |
| V12 | 순서는 리스트에서 드래그로 바꾸고, 칩 순서도 같이 바뀐다 | 신규 (MVP는 v1.1) |
| V13 | 무료 상태에서는 활성(표시 on) 앨범이 3개까지. 4번째를 켜거나 새로 만들면 구매 안내 (리스크 R1) | 신규 |
| V14 | 녹화 중에는 앨범을 바꿀 수 없다 | 신규 |
| V15 | 앱 실행 때와 앨범 리스트를 열 때 기기 갤러리를 다시 읽어, 처음 보는 폴더(사진 1장 이상)를 꺼진 상태로 리스트 맨 아래에 추가한다. 이름이 같은 앨범이 이미 있으면 추가하지 않는다 | 신규 |
| V16 | 첫 가져오기이고 앱 앨범이 하나도 없으면, 시스템 폴더(Screenshots, Download 등)를 뺀 최근 앨범 3개를 켠다 (MVP §7 "최근 앨범 3개"와 같은 취지) | 신규 |
| V17 | 가져온 앨범에서 찍으면 원래 경로에 저장한다. 실패하면 `Pictures/<folderName>`에 저장한다 (R3) | 신규 |
| V18 | 가져온 앨범을 삭제하면 다시 가져오지 않도록 기억한다. 같은 이름으로 새 앨범을 만들면 그 기억은 지운다 | 신규 |
| V19 | 앨범 사진 보기에서 여러 장을 골라 다른 앨범으로 옮기거나 휴지통으로 보낼 수 있다 (Android 11+). Android 10 이하 삭제는 확인 후 영구 삭제 | 신규 (v1.1) |
