# 범위

## 들어가는 기능

| # | 기능 | 레퍼런스 |
|---|---|---|
| F1 | 사진 촬영 → 선택된 앨범에 바로 저장 | `01_camera.png` |
| F2 | 동영상 촬영 (사진/동영상 전환) | `01_camera.png` |
| F3 | 앨범 칩 좌우 스와이프로 저장 앨범 선택 | `01_camera.png` |
| F4 | 새 앨범 만들기 (카메라 칩 끝 `[📔+]`, 앨범 리스트 버튼) | `03`, `04` |
| F5 | 앨범 리스트: 표시 토글, 사진 수, 드래그 정렬 | `05` |
| F6 | 앨범 이름 변경 (이름 탭 또는 스와이프 → 연필). 기기 폴더 이름도 변경 | `06`~`08` |
| F7 | 앨범 삭제 (이름 탭 → 휴지통, 또는 스와이프 → 휴지통 → 확인) | `09`~`12` |
| F8 | 최근 촬영 썸네일 → 앨범 사진 보기 | `01_camera.png` |
| F9 | 설정 화면 | `19_setting_notes.png` |
| F10 | 무료 사용자 활성 앨범 수 제한 안내 | `13_list_free_limit.png` |
| F12 | 기기 갤러리의 기존 앨범(폴더) 전부 가져오기 | 테스트 피드백 (2026-10-08) |
| F11 | 폴더블 펼침 레이아웃 | `15`, `16` |
| F13 | 앨범 사진 여러 장 선택(길게 누르기) → 다른 앨범으로 이동 / 휴지통 | 테스트 피드백 (2026-10-23) |
| F14 | 권한 안내 1장 + 마이크는 동영상 모드 때 요청 | 테스트 피드백 (2026-10-23) |

## 빠지는 기능

로그인, 서버, 클라우드 백업/동기화, 실제 인앱 결제, 잠금 설정, 공유, OCR/AI 분류, iOS 빌드.

## Open 항목에 대한 프로토타입 결정

`sdd/implementation-spec-v2.md` §11의 Open 항목을 아래처럼 정하고 진행한다. 실제 출시 전 다시 검토한다.

| # | 질문 | 프로토타입 결정 | 이유 |
|---|---|---|---|
| O1 | 앨범 삭제 시 사진도 삭제? | **앱 목록에서만 제거.** 기기 폴더와 사진은 남는다 | 되돌릴 수 있고 시스템 삭제 동의 팝업이 없다 |
| O2 | 이름 변경 방식 | **기기 폴더 이름도 변경** (v1.1). 모든 앨범 대상, Android 11+ 시스템 확인 팝업 허용. Android 10 이하는 표시 이름만 | 테스트 피드백: 갤러리 이름이 안 바뀜. 폴더 이름 변경 API가 없어 파일을 새 폴더로 옮긴다 — 리스크 R4 |
| O3 | 설정 내용 | 요금제 안내, 앱 정보, 이용약관, 문의하기, 데이터 안내 | 서버 없이 가능한 항목만 |
| O4 | 무료 제한 | **활성(표시 on) 앨범 3개까지 무료.** 앨범 개수 자체는 제한 없음. 4번째 앨범을 켜거나 새로 만들 때 구매 안내. 결제는 없고 설정의 "프리미엄 체험(테스트)" 스위치로 해제 | 기존 앨범을 전부 가져오므로 개수 제한은 의미가 없음. 리스크 R1 참고 |
| O5 | 기존 기기 앨범 | **전부 가져온다** (Camera 포함). 가져온 앨범은 기본 꺼짐, 첫 실행 때만 최근 앨범 3개를 켠다 | 테스트 피드백: 기존 폴더와 호환이 안 됨. Figma 주석 "어플 내에서 작성한 것만"과 반대 — 리스크 R2 |
| O6 | 플래시 | **넣지 않음** | Figma 화면에 없다 |
| O7 | 이름 길이 | 입력 최대 20자, 칩 표시 10자 초과 시 `..` | Figma 예시 `260730_서울여행..` |

## 리스크 (기획 확인 필요)

| # | 내용 | 현재 설계 | 확인할 사람 |
|---|---|---|---|
| R1 | 무료 제한 기준이 "앨범 개수"인지 "활성 앨범 개수"인지 | 활성 앨범 3개 (개발 측 의도). 프리미엄을 끄면 이미 켜 둔 4개 이상은 그대로 둔다 | 기획자 |
| R2 | Figma 주석은 "앨범 리스트는 어플 내에서 작성한 것만"인데, 기존 폴더를 전부 가져오도록 바꿈 | 전부 가져오고 기본 꺼짐. 리스트에서 기기 앨범은 경로를 작게 표시해 구분 | 기획자 |
| R3 | 가져온 앨범 중 앱이 쓸 수 없는 경로(예: 다른 앱 전용 폴더)가 있을 수 있음 | 원래 경로 저장에 실패하면 `Pictures/<이름>`에 저장 (같은 이름이라 앨범에서는 합쳐 보임) | 개발 (실기기 확인) |
| R4 | 가져온 시스템 폴더(예: `DCIM/Camera`)의 이름을 바꾸면 사진이 새 폴더로 옮겨지지만, 기본 카메라 앱은 계속 `DCIM/Camera`에 저장해 다음 동기화 때 Camera 앨범이 다시 생긴다. 사진이 많으면 이동이 오래 걸린다 | 허용 (사용자 확인 팝업이 뜸). 필요하면 시스템 폴더는 표시 이름만 바꾸도록 제한 | 기획자 |
