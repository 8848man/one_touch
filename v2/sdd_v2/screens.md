# 화면

컴포넌트 이름과 색·크기는 [design_system](../design_system/README.md)을 따른다.
기준 프레임은 360×800dp (Android, 상하 Safe Area 확보).

## 0. 권한 안내 (첫 실행)

Android는 권한 그룹마다 시스템 팝업을 따로 띄우므로 여러 권한을 팝업 하나로 합칠 수 없다. 대신 묻는 횟수와 시점을 줄인다.

- 앱 안 안내 화면 1장: 카메라 / 사진 및 동영상 / 마이크(선택)를 한 번에 설명 → `허용하고 시작하기`.
- 버튼을 누르면 카메라 → 사진·동영상 시스템 팝업이 연달아 뜬다. 둘 다 허용되면 바로 카메라 화면.
- 거부되면 같은 화면에 안내 문구 + `다시 시도` / `설정 열기`. 설정에서 돌아오면 자동으로 다시 확인한다.
- 마이크는 처음 동영상 모드로 바꿀 때만 묻는다. 거부하면 스낵바 "마이크 권한이 없어 소리 없이 녹화돼요."

## 1. 카메라 (`01_camera.png`)

```
┌ 상태바 ───────────────────────┐
│ [≡]                      [⚙] │  상단 바 (어두운 배경)
│                               │
│          카메라 프리뷰          │
│                               │
├───────────────────────────────┤
│          (📷) [🎥]             │  사진/동영상 전환
│ [썸네일]   ( 셔터 )   [전후면]   │
│ 전공 과제자료 (여행) 프로젝트 [📔+] │  앨범 칩 (가로 스와이프), 끝에 새 앨범 칩
│                               │  하단 여백 (내비게이션 바 오터치 방지)
└ 내비게이션 바 ─────────────────┘
```

| 요소 | 동작 |
|---|---|
| `≡` | 앨범 리스트 화면 열기 |
| `⚙` | 설정 화면 |
| 사진/동영상 아이콘 | 모드 전환. 선택된 쪽이 강조색 원 배경 |
| 셔터 | 사진: 촬영 후 저장. 동영상: 탭으로 녹화 시작/정지, 녹화 중 셔터 안쪽이 빨간 사각형 + 경과 시간 표시 |
| 썸네일 | 현재 앨범의 최신 미디어. 탭하면 앨범 사진 그리드 |
| 전후면 | 카메라 전환 (녹화 중 비활성) |
| 앨범 칩 | 좌우 스와이프 또는 탭으로 선택. 선택 칩은 연분홍 배경 + 위쪽 작은 삼각형. 10자 초과는 `..`. 칩 바 높이 48dp |
| 새 앨범 칩 `[📔+]` | 칩 목록 맨 끝. 앨범 아이콘 + `+` 테두리 칩. 탭하면 새 앨범 다이얼로그 (무료 제한 시 구매 안내, V13). 스와이프 선택 대상은 아니다 |

- 저장 성공: 썸네일 갱신, 짧은 셔터 플래시 효과. 실패: 스낵바 "저장하지 못했어요. 다시 시도해 주세요."
- 표시 앨범 0개 (V10): 셔터 비활성, 칩 자리에 "앨범을 만들어 주세요" 버튼 → 새 앨범 다이얼로그.
- 칩 아래에 16dp + 시스템 내비게이션 영역(SafeArea, 최소 8dp)을 비워 홈·뒤로 버튼이 잘못 눌리지 않게 한다.
- 권한 미허용: §0 안내 화면.

## 2. 새 앨범 다이얼로그 (`03`, `04`)

- 제목 "새로운 앨범 추가", 입력 필드 1개 (최대 20자, 자동 포커스), `취소` / `확인`.
- 빈 이름이면 `확인` 비활성. 중복이면 필드 아래 에러 (V4).
- `확인` → 생성 → 해당 앨범으로 선택 이동 (V5). 앨범 리스트에서 열었으면 리스트 맨 아래에 추가.

## 3. 앨범 리스트 (`05`~`13`)

상단 바: `←`(뒤로), `⚙`. 제목 "앨범 리스트". 하단 중앙 떠 있는 버튼 "+ 새로운 앨범 추가".

행: `[표시 스위치] 이름 ……… [사진 수] [≡]`
- 스위치: 표시 on/off (V3, V9, V10).
- `≡` 길게 눌러 드래그 → 순서 저장 (V12).
- **이름을 정확히 탭** → 행이 입력 필드로 바뀌고 오른쪽에 `✓`와 휴지통. 빈 곳을 탭하면 취소.
- 왼쪽으로 스와이프 → 연필(연분홍)·휴지통(분홍) 버튼도 그대로 쓸 수 있다. 한 행만 열린다. 다른 곳 탭하면 닫힌다.
- 연필 → 위와 같은 편집 상태. `✓`/완료 키로 저장, 중복·빈 값이면 스낵바 후 유지 (V4).
- 저장하면 기기 갤러리 폴더 이름도 바뀐다 (V7). Android 11+는 시스템 확인 팝업이 한 번 뜬다. 거부하면 아무것도 바뀌지 않고 편집 상태 유지. Android 10 이하는 앱 속 이름만 바뀐다고 안내.
- 휴지통 → 확인 다이얼로그 "앨범 삭제" / "`{이름}` 앨범을 삭제하시겠습니까?" / `취소` `확인` (V8).
  본문 아래 작은 글씨: "기기에 저장된 사진은 삭제되지 않아요."
- 앨범이 없으면 가운데 "아직 앨범이 없어요" 안내.
- 가져온 앨범은 이름 아래에 기기 경로를 작게 표시한다 (예: `DCIM/Camera`).
- 무료 상태에서 4번째 스위치를 켜면 켜지지 않고 무료 제한 안내 (§6).
- 화면을 열 때 기기 갤러리를 다시 읽어 새 폴더를 추가한다 (V15).

## 4. 앨범 사진 보기 (썸네일 탭)

간단한 3열 그리드, 최신순. 동영상은 재생 아이콘 표시. 사진 탭 시 전체 화면 보기 (동영상은 썸네일만).
Figma에 없는 화면이라 최소 구성으로 만든다.

- **길게 누르기** → 선택 모드. 이후 탭으로 선택/해제, 선택 0개가 되면 종료. 뒤로/`✕`도 종료.
- 상단 바: `✕` · "n개 선택" · `전체 선택`/`선택 해제`. 선택된 칸은 조금 작아지고 분홍 체크.
- 하단 바: `앨범 이동` / `삭제`.
  - 앨범 이동 → 다른 앨범 목록 시트 (꺼진 앨범 포함, 경로 표시) → 그 앨범의 저장 경로로 이동 (Android 11+, 시스템 확인 팝업 1번).
  - 삭제 → 휴지통으로 이동 (Android 11+, 시스템 확인 팝업. 30일 안에 갤러리 앱에서 복원). Android 10 이하는 휴지통이 없어 앱 확인 후 바로 삭제.

## 5. 설정 (`19_setting_notes.png`)

목록형. 상단 바 `←` + "설정".

| 항목 | 동작 |
|---|---|
| 요금제 안내 | 무료(앨범 3개) / 프리미엄(무제한) 설명 시트 |
| 프리미엄 체험 (테스트) | 스위치. 켜면 앨범 수 제한 해제 |
| 앱 정보 | 버전 (`package_info_plus`) |
| 이용약관 | 준비 중 안내 |
| 문의하기 | 이메일 주소 표시 |
| 데이터 안내 | "사진은 기기 갤러리에 저장되고, 앱을 지워도 사진은 남아요. 앨범 목록·순서는 앱 삭제 시 지워져요." |

## 6. 무료 제한 안내 (`13_list_free_limit.png`)

무료 + 켜 둔 앨범 3개 상태에서 새 앨범 만들기 또는 4번째 스위치 켜기 → 다이얼로그
"무료로는 앨범을 3개까지 켜 둘 수 있어요. 다른 앨범을 끄거나 요금제를 확인해 주세요." / `닫기`, `요금제 보기`.

## 7. 폴더블 (`15`, `16`)

화면 폭 ≥ 600dp면 펼침 레이아웃.

| 상태 | 구성 |
|---|---|
| 펼침 기본 | 왼쪽 세로 레일(⚙, ≡), 가운데 프리뷰, 오른쪽 세로 컨트롤(전후면, 셔터, 썸네일), 프리뷰 상단 사진/동영상 전환, 하단 앨범 칩(끝에 새 앨범 칩) |
| 펼침 + `≡` | 왼쪽 절반 앨범 리스트, 오른쪽 절반 폰 레이아웃 카메라. 다시 `≡` 또는 리스트의 `←`로 닫기 |
